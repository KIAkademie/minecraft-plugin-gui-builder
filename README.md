# Minecraft Spigot/Paper – Chest-GUI & Plugin-Generator

Ein Web-Tool für die Entwicklung eigener Minecraft-Server-Menüs (9×3 Inventar-GUI): Slots anklicken, Items und Server-Befehle zuweisen und direkt den fertigen Java-Plugin-Code (`InventoryClickEvent`) sowie die `menus.yml` erzeugen.

- **Direkt im Browser nutzen:** [https://kiakademie.github.io/minecraft-plugin-gui-builder/](https://kiakademie.github.io/minecraft-plugin-gui-builder/)
